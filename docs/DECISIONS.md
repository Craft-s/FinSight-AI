# FinSight AI 工程决策

评审基线日期：2026-10-28。下表保留当时确定的开发默认方案；原说明书保持原样。后续实际选择与阶段边界详见ARCHITECTURE_DECISIONS.md，运行证据见TEST_RESULTS.md；不能单凭决策记录宣称验收通过。

| ID | 默认方案 | 理由与边界 |
|---|---|---|
| D001 | 保留 Vue 3 / TypeScript / FastAPI / Python 3.12 / PostgreSQL 技术栈 | 与目标匹配；采用模块化单体，避免额外服务 |
| D002 | Redis + RQ，正式 worker 在 Linux 容器运行 | 第一阶段同步就接队列；研究复用同一任务基础 |
| D003 | 私有单用户首发 | 保留可信会话、固定 owner、写操作鉴权；多租户不冒充已实现 |
| D004 | 来源快照与规范化规则版本从阶段一建立 | 真实/历史/合成数据可区分并隔离；可重放与追溯 |
| D005 | 公司概览 latest_restated；指定财报研究冻结 accession 与事实快照 | 避免后续重述泄漏到历史报告；显示截止日期与模式 |
| D006 | 金额差分必须同口径；EPS 等非可加指标不差分 | 无直接披露或可验证依据则 N/A |
| D007 | Decimal + NUMERIC，API 精确值十进制字符串 | 防止 JSON 浮点与前端大整数精度损失 |
| D008 | FTS + 章节定位 + 中英术语扩展先行 | 明示检索方式，向量层可选；中文查询有专门验收 |
| D009 | 研究输出 claims + citations/metric references | 出处存在、数值一致与语义受支持分别检查 |
| D010 | 四个 provider 保留 P0；配置变更重新验证 | 不硬编码最新模型 ID/价格；厂商参数按能力转换 |
| D011 | SEC 共享平滑限速默认 3 QPS | 跨 API 与 worker 总量约束；缓存、去重、退避和故障冷却 |
| D012 | 锁定依赖与镜像版本，提交锁文件 | 实际安装测试后确定精确版本，不使用浮动 latest 作为验收基线 |
| D013 | 只从选定 SEC accession 获取必要官方附件 | URL、类型、大小、重定向均受控；不足则明示 |
| D014 | 两层测试：纯离线单元/契约 + PostgreSQL/Redis 集成 | 不以 SQLite 或 Fake 替代真实数据库和供应商验收结论 |
| D015 | 队列/worker 使用 JSON serializer，参数仅传标识 | 降低不安全反序列化与凭据进入队列的风险 |
| D016 | Compose 健康检查 + 独立迁移服务 | API/worker 等待数据库可用且迁移成功 |

补充规则：任务持久化、入队与执行并非天然 exactly-once；通过唯一约束、幂等键、重试记录和恢复机制保证结果可控。报告缓存包含数据/文档哈希、prompt/schema/规则版本、模型配置版本以及 owner。

## 第三阶段执行补充（2026-10-29）

用户已解除第三阶段暂停。继续保留原技术栈和五阶段主线，本轮交付模型配置与结构化指标概览，不提前实施第四阶段正文检索/完整研究报告。

- 采用四个Provider Adapter：OpenAI官方SDK、Google GenAI SDK，以及DeepSeek/Ollama各自HTTP协议。云源固定，不开放自定义compatible URL；参数按厂商协议转换，账户及模型能力通过实际连接小调用验证，不硬编码最新型号或价格。
- 配置使用Fernet加密并绑定owner/provider；每服务商一份配置，版本更新后验证失效，测试结果CAS绑定版本。`MASTER_ENCRYPTION_KEY`缺失或无效仅关闭对应AI密钥操作；财务查询可继续。初始化脚本不打印密钥，丢失/更换主密钥后必须重新保存API Key并重测。
- Ollama地址仅由部署者的`OLLAMA_BASE_URL`指定，不接受UI地址。请求固定origin、禁止重定向和环境代理；部署者须使用受控可信域名或地址，当前未实施DNS固定。Compose只增加环境透传与host-gateway，不新建模型服务。
- 管理员令牌仅存浏览器内存；云Key不回传、不写浏览器持久存储。远程部署须用HTTPS，仍为私有单用户产品，不宣称多租户登录系统已实现。
- 模型列表短期缓存且支持强制刷新，允许空模型草稿先保存Key、枚举后选择，或手动填写精确ID。连接小调用在API线程池中有界执行，概览长任务复用Redis/RQ，只传任务ID。
- AI概览冻结阶段二的结构化事实与来源，后台校验引用、精确值及单位；金额直接从冻结事实呈现。引用/数值正确不等于语义可靠，结果明确说明模型解读未完成自动语义验证。
- 真实PostgreSQL已执行迁移`b31c93`、`c31d94`。离线Provider协议测试不代表在线推理已通过；当前无云Key/Ollama，四家在线调用继续标记未验证。最终测试统计以TEST_RESULTS.md为准。
