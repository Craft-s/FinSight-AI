# FinSight AI 产品说明

更新：2026-11-03。实现与验收状态分别记录；实际执行结果以[测试记录](TEST_RESULTS.md)和[任务清单](TASKS.md)为准。

FinSight AI 为个人研究者提供可追溯的美国 SEC 财务资料和 AI 辅助阅读工作台。核心路径是确认公司身份、理解财务期间与计算依据、阅读披露证据，再选择是否调用模型。产品不提供投资建议，不预测确定的股价方向。

## 用户与部署范围

当前为私有单用户 MVP。浏览者可以读取公司、指标、财报和已保存的证据；本地管理员令牌保护同步、模型配置、研究操作、私有历史和报告下载。身份由后端确定，客户端不能指定 owner。当前没有注册、组织管理或公开多租户服务。

界面支持简体中文和 English。语言选项集中管理，在“设置 → 界面语言”下拉选择；只将语言偏好保存在浏览器，管理员令牌和模型 Key 不写入浏览器持久存储。

## 核心需求与验收行为

| 场景 | 产品行为 | 验收要点 |
|---|---|---|
| 搜索公司 | 按 ticker、CIK 或名称显示候选，用户确认主体 | 保留十位 CIK；不猜测同名公司；当前只支持美国 SEC 主体 |
| 查看财务 | 展示年度/季度、趋势、同比及比率 | 缺失为 N/A；精确十进制字符串带千位分隔；图表不作为精确值来源 |
| 解释口径 | 选择最新重述、截至日期或指定申报 | 展示实际期间、accession、原始 concept、操作数与计算规则；不可比时解释原因 |
| 查看申报与事件 | 10-K/10-Q 与 8-K 分页列表、原始 SEC 链接、修订标记 | 元数据和正文准备状态分开；有列表不等于已保存正文/附件 |
| 无模型使用 | 正常查看上述数据和已保存正文，搜索证据 | 不要求云 Key 或 Ollama；无配置时明确禁用生成并提供设置入口 |
| 配置模型 | OpenAI、DeepSeek、Gemini、Ollama 的模型列表/手动 ID、参数、小型调用测试 | 测试实际模型及参数组合；更新后旧验证失效；列表存在不等于模型可调用 |
| 指标概览 | 异步总结冻结的结构化指标 | 后端计算金额与比率，模型只解释；复制值、单位和引用必须匹配 |
| 正文研究 | 单份定期报告总结、两份定期报告对比、8-K 事件解读、单份申报问答 | 限定所选申报与证据，区分披露事实/推论/未知；证据不足可正常表达 |
| 追溯结果 | 任务状态、取消/重试、历史详情、Markdown 下载 | 冻结证据、文档哈希和配置版本；取消不保证停止已发出的上游请求或免计费 |
| 异常恢复 | 显示依赖不可用、限流、超时、参数不兼容或资料缺失 | 不用测试数据或 Fake 结果代替失败，不声称请求或语义校验成功 |

## 财务与数据规则

后端使用 Decimal/NUMERIC 处理数值，API 精确值以十进制字符串返回。财年按实际起止区间确定，支持不同财年末及 52/53 周年。资产负债表为时点值；可加金额才允许兼容口径的 YTD/Q4 差分；EPS 和比率不能通用差分。同比和比率检查分母、期间与单位，不由模型重算。

`sec_live`、`sec_snapshot`、`synthetic_fixture` 各使用独立数据库，运行模式与数据库绑定不一致时拒绝访问。原始 JSON、HTML 字节及来源哈希保留，后续资料更新不改写已经生成报告的冻结证据。详细字段见[数据字典](DATA_DICTIONARY.md)。

历史演示包含 AAPL、MSFT、NVDA 的真实 SEC JSON 第三方归档，及三份真实定期报告 HTML。每份文件保留来源和许可说明，界面明确“历史快照”，不标为本次直接 SEC 同步或实时数据。合成财务/HTML/模型响应仅存在于隔离测试路径。

## AI 可信性边界

模型输出必须通过结构、当次引用身份、精确值/单位、连续摘录等校验。URL、原文、哈希和位置由后端提供，模型不能自行生成来源。文本匹配只能证明该摘录存在，不能证明语境完整、问题相关性或推论正确；界面与导出文件保留“语义支持未自动验证”的说明。

文档与模型输出均为不可信文本，不执行其中的指令或 HTML。正文获取和模型连接地址由部署者控制，浏览器不能提交任意后端访问地址。

## 五阶段路线

| 阶段 | 保留的目标 | 验收边界 |
|---|---|---|
| 1 | 项目骨架与无 AI 数据闭环 | 无 Key 仍可使用真实公司、财务和申报资料 |
| 2 | 多期间、财务口径与来源 | 三家公司期间转换可解释，边界计算有测试 |
| 3 | AI 双模式与模型配置 | 四种 adapter 已实现；真实云端与 Ollama 切换需可用服务验收 |
| 4 | 检索、事件解读和报告 | 四类研究与引用校验已实现；真实模型报告及直接 SEC 附件需在线验收 |
| 5 | 部署与简历展示 | CI、权限/故障回归、跨系统运行说明、截图、架构图与演示步骤；以实际执行记录区分完成与缺口 |

原方案的第六部分为后续可选增强，不提前引入 PDF 上传、股价、邮件、定时任务、多租户或额外微服务。

## 当前限制

没有可用的真实云 Key 或 Ollama，不能宣称已验证实际模型质量或生成生产研究报告。直接 SEC 同步缺少真实联系信息与可达环境，真实 8-K/EX-99.1 附件在线覆盖待验证。容器构建和部署状态见[测试记录](TEST_RESULTS.md)；没有服务器和域名时不声称公网已部署。
