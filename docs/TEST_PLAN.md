# 测试计划

实际通过数量与命令见 TEST_RESULTS.md。本文件定义持续验收范围，不代表尚未执行项已通过。

1. 领域规则：ticker/CIK、submissions数组对齐、真实文件URL、年度/季度/时点、财年、单位、精度、冲突/缺失、修订和历史版本。
2. SEC契约：受控URL、共享限速、响应大小、错误JSON、403冷却、429/Retry-After、超时及缓存保留。无真实联系邮箱时不做伪造身份的在线测试。
3. 数据库：真实PostgreSQL执行Alembic升降级、唯一约束、去重、快照保留、模式隔离。只在明确命名的测试库运行破坏性清理。
4. 任务：独立Redis DB15、JSON serializer、真Linux worker、重复入队、成功持久化、失败回滚与过期恢复。
5. UI：搜索→选择→指标/图表→来源→财报/事件；访问令牌仅内存；同步完整状态；空态/缺失/错误；桌面与移动端。
6. 模型（阶段三以后）：四provider契约、分页、手动ID、鉴权失败、超时、空列表、能力参数转换、加密和不泄漏。Fake仅测试协议，在线验证逐服务单独报告。
7. 研究（第四阶段）：正文与附件受控获取、清洗/表格/定位、FTS与中文问题、引用/摘录/精确值、证据不足、提示注入、拒答/截断、任务取消/重试、历史与Markdown下载。具体分层如下。
8. 部署：Compose从空卷启动、健康检查、迁移先行、源码与秘密隔离。外部镜像网络失败时不得标记部署通过。

## 第四阶段持续验收（2026-11-03）

| 层次 | 必须检查 | 证据性质 |
|---|---|---|
| HTML纯解析 | 脚本/隐藏内容移除、章节、混合段落、表格标题与列上下文、长块切分、稳定位置/哈希、空文/过大文 | 明确标识的synthetic HTML可验逻辑，不冒充真实财报内容 |
| 受控网络契约 | 所选accession目录、primary URL、附件目录与EX-99.1类型双重确认、重定向/跨目录/危险URL、类型/大小/超时、403/429与共享限速 | MockTransport响应仅验证协议；缺真实User-Agent时不做虚构邮箱直连 |
| PG与数据版本 | d41a01/e41a02升降级、文档原字节sha、版本与chunk唯一约束、数据模式隔离、FTS GIN及中文术语扩展 | 真实PostgreSQL；SQLite关键词降级只能明确标为合成测试 |
| 公共证据API | metadata、JSON location、指定filing公司归属、默认最近十份已有正文范围、无命中/未知中文词、范围提示 | 公开读取不能触发隐式付费模型调用或任意URL抓取 |
| 研究证据 | 未知/重复引用、篡改URL/hash、摘录改写与拼接、精确值/单位/null、数字词与Unicode数值、非法JSON/NaN/重复键 | 确定性校验，不给“引用存在=结论真实”结论 |
| 语义反例 | 披露摘录匹配但语境仍可能不完整、推论仅有引用不代表受到支持、不同期间混淆、检索无命中不等于原文否认 | 固定反例与人工抽检；界面始终显示语义未自动验证 |
| 任务与权限 | owner、字段白名单、只传job_id、冻结上下文、配置version/binding、活动任务复用、成功缓存/force、队列失败、过期恢复、取消阻止发布、冻结重试 | 真实Redis DB15和Linux fork worker；不得清理生产队列 |
| 报告与导出 | 四类任务约束、历史分页、报告读取/下载鉴权、原出处/精确值保留、HTML/Markdown注入、非SEC链接拒绝 | 报告正文按文本处理，导出不能变成可执行源HTML |
| 无Key UI | 正文/证据可浏览、模型与授权缺失提示、研究工作台/历史/报告页中英文、移动布局、失败恢复 | 真实服务页面；不制作假的生产AI报告截图 |

成功研究集成使用测试专用HTTP协议服务器、合成HTML、专用PG测试库和真实RQ，验证的是进程/协议/持久化闭环，不是实际Ollama或云模型推理。另对三份MIT许可的真实历史HTML执行导入与检索，记录其来源和原字节哈希。两类结果不能互相替代。

真实服务验收仍需：可用的各厂商Key或Ollama、真实SEC联系邮箱与可达网络；至少一份真实模型报告由人工核查每个实质claim的出处、语境和推论支持程度。当前没有8-K/EX-99.1真实归档，事件正文与附件覆盖应单独在线验证，不能以10-K/10-Q成功推导通过。第三方XHTML按HTML解析时保留XMLParsedAsHTMLWarning并说明边界，不静默忽略后宣称无损解析。

执行命令沿用README的锁定依赖、`pytest`/`ruff`、前端lint/test/build和Compose配置检查。最终实际数量、失败修复记录、跳过项与在线缺口统一写入TEST_RESULTS.md；本计划不预填尚未完成的最终测试数字或部署结论。

## 第五阶段持续验收

- 后端全套使用专用PostgreSQL库及Redis15；补权限矩阵、非ASCII鉴权、SQL/JSON/日志边界、SEC代理/URL、Ollama危险地址、依赖失败恢复、入队失败及过期任务替换。
- Playwright使用独立端口和真实归档；默认临时SQLite与专用PG分支分别检查。覆盖公司搜索、精确数值/来源/期间、申报事件、语言与会话权限、无模型门禁、真实正文/哈希、PG关键词检索、移动布局及临时响应注入的DOM XSS；不修改生产资料。
- CI分开后端、前端、浏览器与容器job，最小只读权限、超时、取消旧运行和失败截图/trace；容器job从独立卷启动、导入真实归档后运行HTTP烟雾检查。记录配置检查、本机原生进程命令、容器及真实远程运行结果的区别。
- 部署核查Compose语法、迁移/依赖readiness、Nginx静态构建/深链接/API代理/缓存/安全头/长连接测试预算；容器网络不可达时保留失败。
- 备份恢复在新测试库验证逐表行数和内容哈希；不覆盖源数据库、不把数据库备份等同于恢复Redis中未执行的任务。
- 发布包排除.env、密钥、数据库/备份、依赖、测试trace与缓存，保留来源许可证、真实截图、架构图及可复现运行说明。

## UI/UX 重构持续验收（2026-11-04）

- 先在真实公司概览页检查设计 token、金额/单位/同比层级、20px 比率间距、图表/财报预览与精确表格；桌面浅/深及390px截图通过后，再应用研究、设置与其他页面。
- 中英文在320/390/768/1024/1440px检查页面及操作条溢出；允许精确表格在自身容器滚动，不能截断来源、模型ID、哈希和精确数字。
- 主题浅/深/系统及刷新持久化；语言下拉和会话内存独立；顶部搜索Ctrl/Cmd K、方向键/Enter/Escape、无匹配、失败重试；骨架、跳至主要内容、授权Toast。
- ECharts分别验证金额/非金额单位、缺失/零值、精确Tooltip、标签密度、主题和尺寸切换；API原始字符串及顺序不可被图形展示修改。
- 隔离浏览器fixture明确标记TEST ONLY与synthetic_fixture，验证报告事实/推论/未知/证据、DOM转义、超安全整数精度与授权Markdown下载；配置fixture验证Key清除、列表/手填ID和未验证版本禁用，不做真实模型推理声称。
- 运行`pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm test:e2e:check`、`pnpm test:e2e`及`pnpm build`，结果写TEST_RESULTS；不为纯视觉改造虚报重跑后端全套。

## A 股追加验收

- 固定来源协议：JSON精确Decimal、无效/重复键/HTML、身份/人民币/模板校验、完整分页与跨页变化、大小/超时、无重定向/环境代理、Redis限速及403/429冷却；不得为成功绕过来源限制。
- 财务：年度/累计和时点，不差分EPS/比率；总收入/收入、归母/报表净利、货币资金/现金等价物区分；同表可验证操作数、缺失/冲突、银行保险证券毛利拒算及原始精度。
- PG：迁移升降级、CN与SEC模式/身份隔离、来源manifest所有页、空表/失败回滚、重复字节、目录和财务旧ORM对象双方向更新、NOWAIT行锁与提交释放；SQLite不能替代行锁测试。
- 应用：市场选择、中文/代码搜索、路由/最近查看、CNY精确表格/来源、同累计期趋势、公告PDF来源、无权限不POST、浅深中英/320–390px响应式；成功夹具标记TEST ONLY且不写生产。
- 在线：至少沪深京各一家公司，真实API→RQ→PG，核对实际取得期间/完整页/原始哈希/公告原文，保留上游覆盖限制；不推断全目录全历史均通过。
- 部署：CN三环境变量在Compose API/worker一致生效，新增迁移后重启；更新文档及交付，原SEC、真实模型、容器/远程CI的未验收项分别追踪。
