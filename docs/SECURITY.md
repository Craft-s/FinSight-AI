# 安全验收与信任边界

更新：2026-11-03。当前为私有单用户工作台。公开金融资料可读取；所有同步、模型管理、AI调用、私有历史和下载由服务端管理员令牌保护。以下为实际测试覆盖，不等于第三方渗透审计或公开多用户部署验收。命令与最终数量见[测试记录](TEST_RESULTS.md)。

| 检查 | 实现与验证 |
|---|---|
| 写权限与私有读取 | 18个私有端点分别测试无令牌、错误令牌、非ASCII令牌，返回401且无副作用；owner隔离覆盖配置、任务、报告和下载 |
| 凭据 | Fernet载荷绑定owner/provider，查询不返回明文或密文；验证错误、上游错误和未捕获异常不回传敏感输入；浏览器刷新后令牌清除且不在localStorage/sessionStorage |
| 错误日志 | API请求边界仅记录异常类型与request_id，避免Starlette重新抛出原始异常被服务器写入日志；诊断时用request_id关联，不记录请求正文/Key |
| SQL注入 | 公司搜索使用SQLAlchemy绑定表达式；实际注入样例不能绕过筛选或破坏表 |
| XSS | 原HTML不作为可执行页面提供；JSON按文本渲染并设置nosniff；浏览器临时拦截公司名称注入img/onerror/script，验证显示文字、无注入DOM、无弹窗或目标外联，未写入数据源 |
| SSRF与凭据目的地 | 云provider固定origin，分页同源，禁用重定向/环境代理；SEC路径绑定官方端点或指定accession；Ollama只接受部署者配置，拒绝空userinfo、危险地址和映射link-local IPv6 |
| 故障与取消 | 数据库/Redis故障时health降级、ready503，恢复后ready200；研究入队失败可查可重试，过期旧任务不能发布，取消/配置改变阻止在途结果保存；真实Redis/Linux worker空闲恢复测试仍在全套内 |
| 备份恢复 | 真实快照库经pg_dump/pg_restore恢复到新测试库，15表行数与内容哈希一致；源库未修改。此结果不涵盖付费模型任务重放或真实Key解密演练 |
| 交付与静态服务 | 源码包排除本地.env/备份/缓存并扫描已知本机秘密；API no-store，静态页与assets保留nosniff、Referrer-Policy和DENY防嵌入头 |

管理员令牌和主密钥属于部署者信任边界，不能交给不受信任的客户端。当前没有账户注册、公开多租户、CSRF cookie会话或通用自定义模型URL功能。跨网络访问应通过HTTPS私有入口；财务公开读取与私有AI操作权限不同，CORS不代替服务端鉴权。

部署者必须控制Ollama允许的域名和网络，当前未实现DNS固定，不能把任意外部域名当成安全允许列表。禁用环境代理是明确的请求策略，依赖代理的网络环境需由部署者提供受控出网方式，不通过浏览器接受代理地址。

模型验证证明接口与参数可调用；引用校验只能证明身份、精确值或摘录匹配，不能证明语义支持、相关性或投资结论正确。取消不保证上游停止或免计费。真实模型、SEC直接获取、容器完整启动和公网部署仍按测试记录单独验收。

## 源码发布隐私

发布前运行`python scripts/check_public_files.py`，检查工作树候选与真实暂存区；CI亦执行该检查。真实配置、数据库、运行诊断、截图OCR原文和交付目录不提交。图片、历史和未知秘密仍需单独检查，规则脚本不能提供绝对无泄漏保证；本轮结果与作者邮箱保护见[隐私报告](PRIVACY_REVIEW.md)。
