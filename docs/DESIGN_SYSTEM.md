# FinSight AI Design System

本规范对应 2026-11-04 的 Vue 3 / TypeScript 界面实现。目标是让真实财务、原始申报和 AI 解读具有清晰的信息层级，同时保持单用户研究工作台的轻量结构。后续页面优先复用本规范和现有 Element Plus 组件。

## 实现入口

| 文件 | 职责 |
|---|---|
| [styles.css](../frontend/src/styles.css) | 语义颜色、间距、圆角、阴影、工作区布局、公司页、通用组件状态及 Element Plus 变量映射 |
| [theme.ts](../frontend/src/theme.ts) / [ThemeControl.vue](../frontend/src/components/ThemeControl.vue) | 浅色、深色、跟随系统及浏览器偏好同步 |
| [App.vue](../frontend/src/App.vue) / [GlobalSearch.vue](../frontend/src/components/GlobalSearch.vue) | 侧栏、顶部搜索、连接状态、键盘跳转及移动导航 |
| [settings.css](../frontend/src/settings.css) | 偏好、会话权限和模型配置工作流 |
| [research.css](../frontend/src/research.css) | 研究输入、任务、结论、证据卡片和研究记录 |
| [TrendChart.vue](../frontend/src/components/TrendChart.vue) / [chart.ts](../frontend/src/chart.ts) | 图表主题、响应式坐标、精确值 Tooltip 和纯展示辅助函数 |

样式分为全局基础、领域页面和图表局部三层；不为每个页面复制颜色主题。新增颜色应先判断能否由现有语义 token 表达。Element Plus 保留原交互和校验能力，通过 `--el-*` 变量接入主题。

## 颜色

采用灰蓝中性色承载高密度信息，以蓝紫色标识主要操作、当前选项和可追溯链接。财务变化用颜色、正负号和文字共同表达；变化方向不等于投资利好或利空。状态提示同时保留图标或文案。

|---|---|---|---|

| `--text-primary` | `#182334` | `#e8edf6` | 标题、关键数据 |

## 字体与数字

字体栈为 `Inter, -apple-system, BlinkMacSystemFont, 'Segoe UI', 'Noto Sans SC', 'Microsoft YaHei', sans-serif`。未加载外部字体文件，实际字体由本机可用字体决定；不能将截图描述为必定使用 Inter。根字号为 14px，Element Plus 基础字号为 13px。

| 层级 | 当前使用范围 | 规则 |
|---|---|---|
| 页面标题 | 常规 29px；首页响应式 29–40px | 主要标题使用约 600–650 字重，控制字距 |
| 区域标题 | 17px；面板标题 15px | 用于财务表现、趋势、模型连接、证据分区 |
| 正文和表单 | 13px | 说明文字保持约 1.7 行高 |
| 字段标签、辅助说明 | 主要为 12px | 标签与输入保持清晰关联 |
| 技术元数据、微型标签 | 10–11px；少量品牌/移动标签更小 | 只承担辅助信息，不能替代主要业务标签 |
| 核心金额 | 桌面 24–32px，手机 22px | 金额与单位分层，不缩成难以比较的正文 |
| 比率 | 桌面 22px，手机 21px | 明确保留 `%`、倍数等单位 |
| 精确值 | 表格及来源内容 | 右对齐，`tabular-nums`，保留原精度和千位分隔 |

精确值必须通过现有字符串格式化函数展示，保留符号、小数和尾随零。`Number` 转换仅用于图形坐标，不用于替代财务计算、表格值或 Tooltip 精确值。缺失值显示 `N/A` 及原因，不能以 0 或虚构数据补齐。

## 间距、边界与层次

基础间距为 4px：`--space-1/2/3/4/5/6/8/10/12` 分别为 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48px。页面和领域组件按这一节奏布局；图标、文字光学对齐及控件尺寸允许少量局部微调。

- 常规桌面页面左右内边距 32px；1200px 以下 24px，760px 以下 20px，手机进一步压缩。宽屏页面最大宽度 1600px。
- 常规卡片间距 16px，图表与财报预览间距 20px，主要区域分隔 24px；手机卡片间距 10–12px。
- 比率行距离上一组 KPI 为 20px，手机 16px，避免两排卡片粘连。
- 圆角 token 为 6 / 10 / 14px，分别适合小组件、面板和较大容器；Element Plus 常规控件圆角为 7px。
- 默认卡片以 1px 边界和轻阴影承载，不以大面积高光吸引注意。

| 阴影 | 浅色 | 深色 |
|---|---|---|
| `--shadow-sm` | `0 1px 3px #16243e06` | `0 1px 3px #00000014` |
| `--shadow-md` | `0 8px 28px #16243e12` | `0 8px 28px #00000025` |
| `--shadow-popover` | `0 12px 40px #13223d1c` | `0 12px 40px #00000055` |

主要层级由标题、留白、边界和背景决定，阴影用于辅助悬停与弹层识别。

## 工作区与响应式

桌面采用 224px 固定侧栏和 68px sticky 顶栏。导航分为工具、最近查看、来源与工作区身份；“私有单用户”忠实反映当前产品，没有虚构付费计划或账户体系。

顶部搜索复用真实公司搜索 API，支持 Ctrl/Cmd+K、上下方向键、Enter、Escape、清除和失败重试；最多展示 8 项候选。候选含 ticker、公司名和 CIK，保留歧义供用户选择。输入采用 250ms debounce 和请求取消，页面跳转关闭结果弹层。

| 宽度条件 | 布局行为 |
|---|---|
| 大于 1200px | 趋势图与定期财报预览并排，KPI 三列，比率四列 |
| 不大于 1200px | 趋势占满内容宽度，隐藏重复财报预览；完整财报 tab 保留 |
| 不大于 1000px | 侧栏收为 76px 图标栏；链接保留名称与提示 |
| 不大于 760px | KPI、比率各两列，表单与报告主/辅栏转为纵向；财务表格显示横向滚动提示 |
| 不大于 560px | 隐藏侧栏，使用底部导航并留出 safe-area；顶栏优先保留搜索和主题入口 |
| 不小于 1600px | 页面水平内边距 40px，关键金额 32px |

设置页另外在 1150 / 940 / 760 / 560px 调整服务商卡片、偏好面板及配置侧栏；研究页在 1100 / 760px 调整报告与证据布局。这些是内容需要的断点，不要求所有区域同时折叠。以320px视口作最窄验收，body不硬设最小宽度，避免桌面滚动条压缩可用宽度后产生整页横滚。精确数值表格允许在自身容器内横向滚动，不裁掉数字来适应手机。

## 组件状态

| 组件/状态 | 行为和视觉约定 |
|---|---|
| 按钮 | 主操作使用 accent；次操作使用中性边界；Hover 改变边界/背景；禁用态保留原因说明和不可点击语义 |
| Focus | `:focus-visible` 使用 2px accent 外框、3px offset；搜索框用整体 `focus-within` 边界和光晕 |
| Loading | 公司页/指标区、设置、研究列表及任务使用骨架或加载状态；不把旧结果误呈现为新期间结果 |
| Empty | 搜索无匹配、未检索、无正文、未授权、无研究记录分别解释当前状态并提供适当下一步 |
| Error | 图标、错误文字及重试操作；公司加载失败与搜索失败保留可恢复路径 |
| Toast | 复用 Element Plus message；应用主题和 13px 消息文字，短操作反馈不取代持久错误说明 |
| 选中态 | 导航、服务商、模式和模型选择使用 accent 与明确状态文案，不能只改变颜色 |
| 来源 | 原文链接、申报身份、哈希和定位分层呈现；详细技术元数据通过原生 details 展开 |
| 动效 | 常规颜色/边界过渡约 150ms；遵循 `prefers-reduced-motion`，图表同时关闭相应动画 |

页面提供“跳至主要内容”键盘入口；表单输入保留 label、按钮保留可访问名称，状态按需使用 `role="status"` / `role="alert"`。这些实现和交互回归不代表已完成屏幕阅读器全流程认证。

## 财务图表

趋势图跟随语义主题，单序列图例不提供无意义的隐藏切换。金额使用柱形，比例/EPS 等使用折线；不把不同单位混在同一尺度。USD/CNY坐标分别以十亿美元/十亿元人民币展示，单位显式标识；精确值在 Tooltip 和下方表格提供。A股累计趋势只比较历年相同截止日，不能将不同累计长度连成单季度趋势。

- 坐标轴弱化线条与刻度，使用细虚线网格、11px 标签、约四段纵轴分割。
- 横轴根据容器宽度选择标签，保留首尾期间；缺失值断开、零值保留。
- Tooltip 显示实际财年/季度、起止日期、指标名、原始精确值和单位，限制在图表内；长数字按逗号组换行而不丢失位数。
- Tooltip 节点用 `textContent` 赋值，不解析外来 HTML。
- `ResizeObserver` 配合 `requestAnimationFrame` 更新图表，主题、语言和指标变化同时更新。桌面图高 312px，600px 以下局部样式为 280px。
- 图形提供可访问描述，并指向同页精确表格作为非图形阅读方式。

## 研究与设置模式

研究页面将研究范围、模型与提交、实际任务状态、结论、证据来源分开。结论继续区分披露事实、模型推论、未知及方法限制；引用存在不等于自动证明语义支持。证据长摘录可展开，SHA-256 可直接核对，定位和 chunk 信息按需展开。

分析过程只显示后端实际状态，不伪造逐步完成、百分比或预计时间。没有授权、可用模型或资料时给出相应引导，不能为了填满页面生成假报告。

设置按“偏好设置 → 会话权限 → 模型连接”组织。模型连接按“连接信息 → 选择模型 → 验证与启用”组织，并提供当前状态侧栏。读取列表与手动输入 ID 保持互通；没有读取列表时不假报空列表。未验证的配置不能设为默认，修改配置后继续遵守已有版本验证规则。云端 Key、会话令牌与受控 Ollama 部署地址保持原安全边界。

主题偏好只存储 `finsight.theme = light | dark | system`；缺失或无效时回到浅色。`system` 监听系统外观变化；其他标签页变更通过 storage 事件同步。语言仍从设置下拉选择并保存语言枚举；凭据不因外观偏好而进入 localStorage。

## 后续维护

本轮保留 Vue 3、TypeScript、Element Plus 与 ECharts，没有加入 Tailwind CSS 或 shadcn-vue。现有组件已经承担选择器、日期、弹层、表格和校验，当前主要问题是视觉语义与信息组织；再引入一套组件/样式体系会增加迁移成本和交互回归面。

新增页面应优先复用 panel、page、字段说明和状态模式；新增业务组件才提取新的通用抽象。视觉修改后检查中英文、浅深主题、长精确数字和移动布局，并运行现有前端检查及相关交互测试。测试结果与尚未验证项目统一记录在[测试记录](TEST_RESULTS.md)，本规范不替代验收证据。

实现参考：[Element Plus 深色模式](https://element-plus.org/en-US/guide/dark-mode.html)、[ECharts 容器尺寸](https://echarts.apache.org/handbook/en/concepts/chart-size/)。
