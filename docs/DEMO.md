# FinSight AI 演示流程

这份流程使用真实 SEC **历史归档**。它可以在没有模型 Key 的情况下演示已实现的财务、来源与证据功能；不把测试专用模型响应、空研究历史或历史快照包装成实时在线 AI 报告。

## 演示前准备

按[部署指南](DEPLOYMENT.md)启动前端、API、PostgreSQL、Redis 和 Linux worker，迁移并导入三家公司 JSON 与三份 HTML。确认 `/health` 的 database/redis 为 ok，source_kind 为 sec_snapshot。当前开发机可以用 `scripts/start_local.ps1` 恢复已有环境。

开发首页为 `http://127.0.0.1:5173`，Compose 首页为 `http://127.0.0.1:8080`。若需要展示管理员操作，演示前在设置页输入本地令牌；投屏和录像不显示该值，刷新后令牌会清除。没有真实模型时保持无模型状态，不临时写入 Fake 配置。

## 无 Key 路径

| 步骤 | 操作 | 可向面试官说明的设计 |
|---|---|---|
| 1. 确认主体 | 首页搜索 AAPL，确认 Apple 和十位 CIK 后进入公司页 | ticker 可以改变，CIK 是主体身份；搜索不会猜测歧义 |
| 2. 读取指标 | 查看年度趋势和指标明细，切换季度/财务期间 | 后端按实际期间计算，精确字符串与图表展示单位分开；N/A 不填零 |
| 3. 解释来源 | 点击一项金额或利润率的来源；切换指定申报/截至日期口径 | 查看原始 concept、期间、accession 以及差分/比率操作数；历史查询不覆盖最新视图 |
| 4. 阅读申报 | 打开财报列表，筛选 10-K；查看 8-K 事件列表 | 列表元数据不等于正文/附件已经保存，事件不等于确定的价格方向 |
| 5. 检索真实正文 | 从 Apple `0000320193-24-000123` 的研究入口进入 AI 研究，选择该正文，搜索 `revenue` 或 `风险` | 展示英文 FTS/中文术语扩展、原文片段、SEC 来源、章节/位置和文档哈希 |
| 6. 展示边界 | 观察未配置/未验证模型时不能创建研究任务；查看研究记录的授权/空态 | 基础数据不依赖模型，证据不足和不可用服务不会换成虚构结果 |
| 7. 切换语言 | 设置 → 界面语言 → English，再返回公司页 | 翻译、日期、金额展示、错误与无障碍标签共用语言注册；只持久化语言 |

已提供正文为 Apple FY2024 10-K、Apple 截至 2024-06-29 的 10-Q 和 NVIDIA FY2023 10-K；它们不等同于公司概览默认展示的最新保存期间。应按 accession 选择对应正文，并明确其时间范围。

没有命中时展示检索范围和提示，不把缺乏检索命中解释为原财报没有披露。第三方归档下载时间与原申报日期、原 SEC 抓取时间不同，具体来源和许可证可以打开 `data/` 下的 manifest 查看。

## 有真实模型后补做的路径

以下是待验收流程，当前缺少可用云 Key/Ollama，不能提前记为通过：

1. 在设置页保存真实服务配置，自动枚举或手填精确模型 ID，执行小型真实文本连接测试；说明该请求可能计费。
2. 选择已验证配置与已有正文的指定申报，创建单份总结，观察 queued/running/终态；用相同输入再次提交，验证在途复用或成功缓存。
3. 打开成功报告，逐个核查实质事实的引用、连续原文、期间与数值；区别“原文匹配”和“语义支持未自动验证”。
4. 从当前授权会话下载 Markdown，核对其证据与页面一致，下载 URL 中没有令牌。
5. 使用独立新任务检查取消/失败重试；不要为演示盲目重复付费调用。取消只能保证不发布被取消任务的结果，不能保证上游停止或免计费。
6. 再分别验证两期对比、问答，以及具备真实 8-K 主文和附件时的事件解读。四类协议测试通过不替代这一步。

真实生成的报告也需要人工核查，保留模型、配置版本、资料范围、来源时间和方法限制。报告质量没有自动语义正确率数字，不使用没有实际评测的准确率。
