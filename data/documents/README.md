# 真实历史SEC HTML归档

本目录是第三方公开归档中的真实财报HTML，不是合成测试资料，也不是本次直接从SEC下载的实时正文。原始字节未修改。三个文件均固定到[EdgarTools](https://github.com/dgunning/edgartools) commit `3931b22077eee1e0d2b77a8c5a61ab415d51ae0b`，与既有JSON快照使用相同固定版本。仓库MIT许可证副本见`LICENSE-EDGARTOOLS.txt`；来源归属仍为各公司的公开SEC申报。

实际申报身份以已保存的SEC submissions元数据匹配，并与HTML中的dei公司名、表单、期末日期核对。段落数来自`sec-html-v1`实际解析，不是测试覆盖率或性能指标。

各目录的manifest记录原SEC URL、固定归档URL、commit、原字节SHA-256及许可证来源。`fetched_at`是本次从第三方归档下载文件的实际时间；原SEC抓取时间未知，`archive_captured_at=null`。不得把该时间说成SEC披露时间或实时更新。归档哈希仅验证与已下载固定版本的一致性，不替代对第三方归档真实性的独立认证。

这些文件仅用于`sec_snapshot`专用数据库；在线模式和合成测试模式不能混入。测试用HTML位于`backend/tests/test_documents.py`，不会作为产品金融资料导入。本目录没有8-K或EX-99.1事件附件，不能据此宣称事件正文范围完整。在线正式使用仍需部署者的真实SEC联系邮箱与可达网络。
